Digit Swarm

One weight-shared transformer block, applied 16 times to a flock of points in R6. The points start on a sunflower disk and settle into a handwritten digit. It runs live in your browser.

The picture plane. Each boid starts at a fixed spot on the disk, and that spot is its identity, so there is no positional encoding. Colours follow the starting position, so the same boid has the same colour in every digit.

c₁, c₂

The prompt: one of ten points on a circle of radius 2, the same for every boid. Pinned, so the block can read it but never write it.

s₁, s₂

The style: one global draw from N(0, I), so it does not average out the way per-boid noise would. Free state: the block writes to it, which lets paths cross in the picture plane.

Both models have 69,384 parameters: 2 heads and a 6→256→256→6 GELU feed-forward, trained on 64 boids. The dynamics are close to mean-field, so other swarm sizes work too. The original was trained on 16 steps; the stable model was fine-tuned to stay put through step 32. Anything longer extrapolates. Keys: 0–9 pick a digit, space plays, s samples a style.
